## LaTeX 問題エディタ v0.1.0

数学の問題と解答を GUI で LaTeX 入力し、プリントや大学入試形式の PDF を作るデスクトップアプリの最初の版です。

### ダウンロード
- **Windows**：`LaTeX Problem Editor Setup 0.1.0.exe`（インストーラー）
- **macOS（Apple シリコン / M1 以降）**：`LaTeX Problem Editor-0.1.0-arm64.dmg`（または `.zip`）

コード署名をしていないため、初回起動時に警告が出ます。
- Windows：SmartScreen の「Windows によって PC が保護されました」→「詳細情報」→「実行」
- macOS：アプリを右クリック →「開く」（それでも開けない場合は「システム設定」→「プライバシーとセキュリティ」→「このまま開く」）

PDF 作成には LuaLaTeX（Windows: TeX Live / macOS: MacTeX）が必要です。TeX がなくても「簡易PDF」で保存できます。

### 主な機能
- LaTeX ソース編集＋ライブプレビュー、記号パレット、見たまま数式入力（MathLive）
- 書式ボタン（太字・斜体・下線・サイズ・色）
- 図・グラフ：関数グラフ・作図・画像を GUI で挿入（PDF は TikZ）
- Claude などの AI の回答を、数式ごと LaTeX に変換して取り込み
- Word（.docx）の問題集を、数式（OMML）ごと LaTeX に変換して取り込み
- 数式を Word 用（MathML）にコピー
- レイアウト／テーマ：大問見出し・小問番号・余白・用紙などを GUI で設定、プレビューで解答スペースをドラッグ調整
- 大学入試の体裁テーマ：東大・京大・東北・名大・九大・北大・東京科学大・一橋・神戸・慶應（理工）・新潟（公開されている問題冊子をもとにした近似）
