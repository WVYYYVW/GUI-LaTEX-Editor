## LaTeX 問題エディタ v0.3.0

物理・化学の問題に対応し、AI に問題を作らせるためのプロンプトを組み込みました。

### ダウンロード
- **Windows**：`LaTeX Problem Editor Setup 0.3.0.exe`（インストーラー）
- **macOS（Apple シリコン / M1 以降）**：`LaTeX Problem Editor-0.3.0-mac-arm64.dmg`（または `.zip`）
- **macOS（Intel）**：`LaTeX Problem Editor-0.3.0-mac-x64.dmg`（または `.zip`）

macOS で初めて開くときは、アプリを右クリック →「開く」（開けないときは「システム設定」→「プライバシーとセキュリティ」→「このまま開く」）。「壊れているため開けません」と出るときは、ターミナルで `xattr -dr com.apple.quarantine "/Applications/LaTeX Problem Editor.app"` を実行してください。

### 物理・化学
- 化学式 `\ce{H2SO4}`・`\ce{2H2 + O2 -> 2H2O}`・`\ce{N2 + 3H2 <=> 2NH3}`、単位 `\qty{9.8}{m/s^2}`・`\unit{\kilo\ohm}` を文章中にそのまま書ける。PDF では普通の LaTeX に変換するので、mhchem・siunitx が入っていない TeX でもプレビューと同じ見た目
- 大問の中の「部」`\Part`（I, II / 〔I〕 / A, B / ⑴ など）、穴埋めの空欄 `\blank{ア}`（枠・［ ］・（ ）・〔 〕・下線）
- 設問番号に「問1」「問 1.」「問⑴」「設問(1)：」「⒜」「ア」を追加。大問番号に「物理問題 I」「第 I 問」を追加
- 記号パレットに「物理」「化学」の欄。作図に物理の部品（ばね・抵抗・コンデンサー・電池・コイル・スイッチ・床と壁・物体・力の矢印・寸法線）
- 設定に「科目」（数学・物理・化学）：記号パレット・大学テーマの一覧・表紙の科目名が科目に合わせて切り替わる
- 大学入試の体裁テーマに物理・化学を追加（東京・京都・東北・名古屋・九州・北海道・東京科学・神戸・慶應義塾（理工）の 9 大学 × 2 科目。公式サイトの令和 8 年度の問題 PDF を画像で計測）

### AI 用プロンプト
- ツールバーの「AI用プロンプト」：Claude・ChatGPT などに渡すプロンプトを作ってコピー。「問題だけ」か「問題と解答」か、科目、依頼の内容を選べる
- 貼り付け用：AI は `【問題1】…【解答1】…` の区切りで書くので、「AIの回答を貼り付け」に一度貼るだけで、問題文と解答をまとめて上書き（または新しい問題として追加）できる
- .mathprob ファイル用：ファイルを作れる AI に問題集ファイルを書き出させ、そのまま「開く」で読める。JSON を貼り付けても取り込める

### 組版の修正
- 和文を欧文と同じ大きさで組むようにした（これまでは ltjsarticle の既定で和文が 0.92 倍になり、プレビューや実物の冊子より 1 行の字数が多かった）。大学テーマの上の余白もこれに合わせて調整
- 見出しが本文の上にあるテーマで、2 つ目以降の段落の 1 字下げが効いていなかったのを修正
- 下書き用紙の枚数を指定できるようにした（東京科学大学は 2 ページ）

### 画面の修正
- 選択中の枠・キーボードのフォーカス枠が、欄の端で切れていたのを修正
- 窓が狭いとツールバーの右端のボタンが画面の外に出ていたのを、折り返して表示するように
- プレビューの「改ページ」の目印が次の大問の 1 行目に重なっていたのを修正
- 作図の点の行で削除ボタンが次の行に落ちていたのを修正、説明の `\` が `¥` で表示されていたのを修正
