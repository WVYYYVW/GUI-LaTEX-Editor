## LaTeX 問題エディタ v0.4.0

LaTeX を知らなくても問題を書けるようになり、大きな問題集でも軽くなりました。共通テストの体裁、自動更新にも対応しました。

### ダウンロード
- **Windows**：`LaTeX-Problem-Editor-Setup-0.4.0.exe`（インストーラー）
- **macOS（Apple シリコン / M1 以降）**：`LaTeX-Problem-Editor-0.4.0-mac-arm64.dmg`（または `.zip`）
- **macOS（Intel）**：`LaTeX-Problem-Editor-0.4.0-mac-x64.dmg`（または `.zip`）

macOS で初めて開くときは、アプリを右クリック →「開く」（開けないときは「システム設定」→「プライバシーとセキュリティ」→「このまま開く」）。「壊れているため開けません」と出るときは、ターミナルで `xattr -dr com.apple.quarantine "/Applications/LaTeX Problem Editor.app"` を実行してください。

**この版から自動更新に対応しました。** 次の版からは、アプリが新しい版を知らせます（Windows は自動で入れ替わります）。今回だけは、上のファイルから入れ直してください。

### 書きやすく
- 行の先頭に `(1) ` と書くと小問になります（番号の形はレイアウトで決まる）。Enter で次の番号、番号だけの行で Enter なら小問から抜けます
- `\item`・`\begin{enumerate}`・`\blank{ア}` などの命令は、エディタで「小問」「小問ここから」「空欄 ア」のような札で表示します（カーソルのある行は元の文字のまま）
- エディタの上に「小問 (1)」「数式」「グラフ・図」ボタン
- 題名を空にしておくと、問題文から「二次関数の最大・最小」「確率」のような題名を自動で付けます
- 「一覧」「プレビュー」ボタン（Ctrl/⌘+Shift+L / P）で左右の欄を隠し、エディタを広く使えます
- 問題の一覧表（左上の「表」、Ctrl/⌘+Shift+T）：題名・難易度・タグ・小問の数・配点などを表で見て並べ替え。★ で難易度も変えられます

### グラフ・図
- 関数グラフに「範囲を自動で合わせる」「要点を打つ（切片・極値・交点）」。縦の直線は `x=2`
- プレビューで、手書きの TikZ（`\begin{tikzpicture}`）も表示（TeX があれば、LuaLaTeX で組んだものをそのまま表示）。`\includegraphics` の画像（PNG・JPEG・PDF）も表示

### 体裁
- **共通テスト（数学①・数学②）**：表紙・注意事項・柱・ページ番号・解答欄の枠（`\blank{アイ}`）まで冊子に近づけたテーマ
- 大学テーマに表紙を追加。大学を追加：早稲田（理工）・広島・千葉・東京理科・熊本・岡山・金沢
- これまで表せなかった体裁（「問」だけ太字、⑴ の中の ⒜ の段、部の字下げなど）に対応
- テーマ「シンプル」「まっさら（ここから作る）」。大問の見出しを LaTeX で自作でき、「LaTeX で調整」でレイアウトの命令を書き足せます

### 軽く
- プリント全体のプレビューを、変わった問題だけ差し替え、見えている所から描くようにしました（50 題の問題集で、問題を選ぶ 2.4 秒 → 0.01 秒、プリント全体を開く 2.4 秒 → 0.5 秒）
- 数式の組版を覚えておき、変わっていない数式は組み直しません

### そのほか
- 問題集ファイルの拡張子を `.mpb` に短くしました（以前の `.mathprob` もそのまま開けます）
- AI 用プロンプト（ファイル用）でファイル名を指定できます（空欄なら AI が内容に合わせて付けます）
- TeX にパッケージが足りないとき、足りないものと入れ方を表示します（v0.3.1）
- 修正：小問の間に空行があるとプレビューで番号が消える／窓が低いとエディタが見えなくなる／狭い窓で書式ボタンが隠れる／TeX Live を全部入れた環境で ⑴・ア の小問番号で PDF が作れない
