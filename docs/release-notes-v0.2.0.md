## LaTeX 問題エディタ v0.2.0

### ダウンロード
- **Windows**：`LaTeX Problem Editor Setup 0.2.0.exe`（インストーラー）
- **macOS（Apple シリコン / M1 以降）**：`LaTeX Problem Editor-0.2.0-mac-arm64.dmg`（または `.zip`）
- **macOS（Intel）**：`LaTeX Problem Editor-0.2.0-mac-x64.dmg`（または `.zip`）

Apple の開発者証明書による署名・公証をしていないため、macOS では初回起動時に警告が出ます。
1. dmg を開き、アプリを「アプリケーション」フォルダにドラッグ
2. アプリを右クリック →「開く」。開けないときは「システム設定」→「プライバシーとセキュリティ」→ 下の方の「このまま開く」
3. それでも「壊れているため開けません」と出るときは、ターミナルで次を実行してから開く
   `xattr -dr com.apple.quarantine "/Applications/LaTeX Problem Editor.app"`

PDF 作成には LuaLaTeX（macOS: MacTeX / Windows: TeX Live）が必要です。

### v0.1.0 からの変更
- 表紙（試験問題冊子の表紙：年度・科目・試験時間・注意事項・受験番号欄）を追加
- 大学テーマの余白・大問番号・小問の位置を、実物の問題冊子の画像解析で合わせ直した（上下左右の余白を個別に設定、番号の張り出し・枠の大きさ・字間）
- 小問 (1)(2) のまとまりの前後にも、小問どうしと同じ空きを入れる
- 句読点「，。」の統一で「．」が「。」にならなかったのを修正
- Word 取り込み：数式段落の ∫・Σ・分数・lim を Word と同じディスプレイの大きさに
- Word 取り込み：●◎ などの記号の並びを文章として扱い（途中で折り返せる）、Word で手で入れた改行を前の行につなぐ
- 小問を入れ子にすると PDF 作成が止まる不具合を修正
- macOS 版：Intel Mac 用（x64）も作成。アドホック署名を付け、Apple シリコンで「壊れている」と出にくくした
